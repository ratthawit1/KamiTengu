# แผนใช้ AI Marketing Agent

แนวคิดหลัก: **AI ทำงานจำเจและงานเขียน ส่วนคนในครอบครัวทำหน้าที่ตรวจ อนุมัติ และปิดการขาย**

## ทีม Agent 6 ตัว

| Agent | หน้าที่ | คนต้องทำอะไร |
|---|---|---|
| **1. Content Agent** ✍️ | เขียนโพสต์ แคปชั่น สคริปต์ TikTok และข้อความโปร ได้ทีละ 2 สัปดาห์ | ตรวจและกดโพสต์ (~30 นาที/สัปดาห์) |
| **2. Ads Agent** 📊 | เขียนข้อความโฆษณาหลายแบบ และอ่านผลโฆษณารายสัปดาห์ที่ copy มาวาง แล้วแนะนำว่าตัวไหนควรปิด ตัวไหนควรเพิ่มงบ | ปรับงบตามคำแนะนำ |
| **3. Lead Response Agent** 💬 | แชทบอทใน LINE OA ตอบคำถามที่พบบ่อย (ราคา ขนาด ทำเล โปร) เก็บข้อมูลลูกค้า และนัดวันชมบ้าน | รับช่วงต่อเมื่อลูกค้าพร้อมนัดหรือถามเรื่องเฉพาะ |
| **4. Loan Pre-check Agent** 🏦 | คำนวณค่างวดและรายได้ที่ควรมี บอกลูกค้าเบื้องต้นว่ามีโอกาสกู้ผ่านไหม และควรเตรียมเอกสารอะไร | ยืนยันกับธนาคารจริง |
| **5. CRM & Follow-up Agent** 📋 | ติดตามลูกค้าที่เงียบไป ส่งข้อความหาลูกบ้านเดิมเรื่องโครงการแนะนำเพื่อน และเตือนนัดหมาย | ตรวจรายชื่อก่อนส่ง |
| **6. Report Agent** 📈 | สรุปตัวเลขทุกวันจันทร์ ได้แก่ ลูกค้าเข้า นัดชม จอง ต้นทุน และสิ่งที่ควรปรับ | อ่าน 5 นาทีแล้วตัดสินใจ |

### 🚫 กฎเหล็กของ Agent

- ห้ามรับปากว่ากู้ผ่าน
- ห้ามลดราคาเอง
- ห้ามสัญญาเรื่องที่ไม่มีในสัญญาจริง
- เรื่องเงินและสัญญาต้องส่งต่อให้คนตอบเสมอ

## แผนติดตั้งเป็น 3 เฟส

| เฟส | ระยะเวลา | เครื่องมือ | ค่าใช้จ่ายโดยประมาณ |
|---|---|---|---|
| **1. เริ่มทันที** | สัปดาห์ 1-2 | ใช้ Claude แบบแชท สร้าง "Project" ใส่ข้อมูลโครงการไว้ แล้วใช้คำสั่งสำเร็จรูปสำหรับ Agent 1, 2, 4, 6 | ~700 บาท/เดือน |
| **2. เชื่อมระบบ** | สัปดาห์ 3-6 | LINE OA + แชทบอท (Agent 3) + Google Sheets เป็นฐานข้อมูลลูกค้า | ~1,500-3,000 บาท/เดือน |
| **3. อัตโนมัติ** | เดือนที่ 3 ขึ้นไป | เครื่องมือ Make หรือ n8n เชื่อม LINE, Sheets และ Claude API ให้ข้อมูลลูกค้าไหลเข้าระบบเองและส่งรายงานอัตโนมัติ | ~2,000-5,000 บาท/เดือน |

## แบ่งงานในครอบครัว (ตัวอย่าง)

- **คนที่ 1 (ดูแลการตลาด):** ตรวจคอนเทนต์ที่ AI ร่าง ดูแลโฆษณา และอ่านรายงาน (~3-4 ชม./สัปดาห์)
- **คนที่ 2 (ดูแลการขาย):** รับลูกค้าต่อจากแชทบอท พาชมบ้าน ปิดการขาย และประสานธนาคาร
- **เจ้าของ:** อนุมัติโปรโมชั่นและงบ และตัดสินใจทุกวันจันทร์จากรายงาน

## 🚀 คำสั่งสำเร็จรูป

### ① ข้อมูลหลักของโครงการ

ดูใน [`ข้อมูลโครงการ.md`](ข้อมูลโครงการ.md) แล้วใส่ไว้ใน Claude Project ครั้งเดียว Agent ทุกตัวจะใช้ร่วมกัน

### ② Content Agent

```
วางแผนคอนเทนต์ 2 สัปดาห์ (Facebook 6 โพสต์ + TikTok 4 คลิป)
แต่ละชิ้นระบุ: วันโพสต์ / หัวข้อ / แคปชั่นเต็ม / ภาพหรือฉากที่ต้องถ่าย / CTA ให้ทัก LINE
ผสม: พาชมบ้าน 40%, ผ่อนเท่าไร/ความรู้กู้บ้าน 30%, รีวิวลูกบ้าน 20%, โปร 10%
```

### ③ Report Agent

```
นี่คือผลโฆษณาและยอดลูกค้าสัปดาห์นี้: [วางตัวเลข]
สรุปเป็น: ตัวเลขสำคัญ / เทียบสัปดาห์ก่อน / โฆษณาตัวไหนควรปิดหรือเพิ่มงบ /
3 สิ่งที่ต้องทำสัปดาห์หน้า เขียนให้เจ้าของอ่านจบใน 2 นาที
```
