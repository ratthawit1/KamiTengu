# ข้อมูลหลักของโครงการ (Project Brief)

ไฟล์นี้คือข้อมูลที่ AI Agent ทุกตัวใช้ร่วมกัน **กรอกช่อง `[ใส่]` ให้ครบก่อนใช้งาน**

## ข้อมูลธุรกิจ

- ชื่อโครงการ: บ้านทรัพย์เศรษฐี
- รูปแบบ: สร้างบ้านเพื่อขาย ดำเนินการในนามบุคคลธรรมดา หุ้นกับครอบครัว
- เริ่มดำเนินการ: ปี 2020
- ผลงาน: ส่งมอบแล้วประมาณ 60 หลัง
- คงเหลือ: ประมาณ 6 หลัง

## ข้อมูลบ้านที่เหลือ

- ทำเล: [ใส่ จังหวัด / อำเภอ / จุดเด่นใกล้เคียง]
- ราคา: [ใส่] (แผนตอนนี้ใช้ค่าสมมติประมาณ 2.5 ล้านบาท/หลัง)
- ขนาด: [ใส่ ห้องนอน / ห้องน้ำ / ตร.ว. / ตร.ม.]
- จุดเด่น: [ใส่ 3-5 ข้อ]
- โปรโมชั่นปัจจุบัน: [ใส่]
